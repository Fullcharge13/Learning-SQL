# 심화 1~6장 디딤돌 조사 (v0.2 작업 2)

> 작성 2026-11-06 · 바탕 커밋 `6c3f798`(갈래 `v0.2`) · 설계서 `docs/specs/2026-11-06-심화-1-6장-설계.md`(이하 「설계」) §2·§3·§4-1
> 방법: 리아 `ria-python/docs/specs/2026-11-01-심화-13-17장-디딤돌.md`와 같은 모양. 심화 레슨마다 (a) 심화가 직접 가르칠 것, (b) 말없이 기대는 기초를 적고, (b)가 본 과정 어디서 가르쳐졌는지 `data/lessons/ch1~6.js`의 카드·문제·정답을 펼쳐(덤프 스크립트로 모든 SQL·말풍선·보기·해설을 뽑아 검색) 대조했다.

## 0. 가정과 읽는 법

- **학습자는 심화를 하나도 하지 않았다.** 그리고 심화 셋은 장 평가 뒤 함께 열리고 순서가 없다(설계 §3 「열림·보상」). 그래서 **A3도 A1·A2를 했다고 기대하지 않는다**: A3가 A1·A2 모양(괄호·`%`·주석·NULLIF 등)을 쓰면 A3 첫 카드에서 다시 짧게 보여 준다.
- 「✓ N-k」 = 본 과정 레슨 N-k에 있음. 근거 칸은 그 레슨의 어디(카드 1·2, 문제 q 앞부분, build id)인지를 적었다. 「✗」 = 본 과정에 없음 → 「보강」(본 과정에 넣음) 또는 「심화 안」(그 심화 카드에서 직접 가르침).
- 「조립」은 계획한 build 정답과 카드 수. 1~5장 심화는 판정 R51(1~3토큰 구절 카드, 30칸)로 셌다. 카드 더미 = 정답 카드 + 헷갈림 2장 이상, 12장 이하(R34). 정답·행 수는 `data/market.sql`로 실제로 돌려 확인했다(`tests/content.js`의 `openEngine`).
- 낱말 범위: N장 심화 = `GRAMMAR[1..N]` + `ADVANCED_GRAMMAR[N]`(R53, 앞 장 심화 낱말은 이어지지 않음). 1장 심화는 2장 모양(`+ - * /`, 쉼표 열 목록 = 2-1 「열 고르기」)을 쓰지 않는다(R52). 쉼표는 `FORMS`에 없어 점검기가 잡지 못하므로 손으로 지킨다.
