# 「두억이의 가게」(v0.3) 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 3장 평가 뒤 열리는 놀이터 「두억이의 가게」 — 학습자가 카드로 만든 읽기 전용 SQL이 매일 아침 임시 장부에서 돌고, 찾은 행을 게임이 행동(채우기·할인·진열·값 매기기·보고)으로 받아 하루 장사를 굴린다.

**Architecture:** 가게 상태는 `save.stall`(JSON). 「장 열기」마다 `ledger.js`가 상태로 장부 SQL을 만들고, 작업자가 새 메모리 DB에 올려 잠근 뒤 켜진 칸 질의를 돌려 결과를 돌려준다. `slots.js`가 결과를 행동으로 바꾸고, 순수 함수 `day.js`가 하루(아침 행동·손님·정산)를 계산해 사건 목록을 낸다. 화면은 사건을 재생만 한다.

**Tech Stack:** 순수 ES 모듈(브라우저·Node 공용), sql.js 1.15.2(작업자), Node `node:test`, Playwright(`tests/flow.py`), esbuild 한 장 빌드(`build.py`).

**Spec:** `docs/specs/2026-11-11-두억이의-가게-설계.md`

## Global Constraints

- 화면 글은 모두 한국어. 학습자 입력은 터치·카드만(타자 없음).
- 학습자 SQL은 읽기 전용: 기존 `checkReadOnly`·`execOne` 그대로, 장부 DB는 `PRAGMA query_only = ON`.
- 보상: 의뢰마다 **XP 5**(`earnXp`로, 하루 목표·연속 기록에 들어감). 엽전은 주지 않음. 가게 돈(냥)은 게임 안에서만.
- 저장 `saveVer`는 1 그대로. `save.stall`이 없으면 `null`(가게를 처음 열 때 만듦), 있으면 `cleanStall`로 채움.
- 수치 시작값(설계 §2·§4)을 `data/stall.js` 한 곳에. 시뮬레이션으로 바꾼 값은 LOG에 전후 표로.
- 같은 (상태, 칸 결과) → 같은 하루(결정적). 난수는 `rngFor(seed, day)`로만.
- 가게 열림 = 3장 평가(`3-5`) 통과. 칸·카드 열림 = 그 장 평가 통과.
- SQL을 화면에 보일 때 `escCode`. 그림은 SVG 코드(이미지 파일 없음). 터치 대상 44px 이상, 아이폰 17 넘침 없음. 움직임 줄이기면 재생 건너뜀.
- 서비스 작업자 캐시 접두사 `dueogi-`, `ria-` 캐시는 지우지 않음.
- 커밋 작성자 `Claude <noreply@anthropic.com>`, 메시지 끝에 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` · `Claude-Session: https://claude.ai/code/session_01LbVuTK2Xv5GsLmmLTanffi`. main 합치기·gh-pages는 하지 않음.

## Review Focus

1. **옛 저장·깨진 가게 저장**(stall 없음, 칸 id 모름, 음수 돈, 재고 99, 카드 id 없어짐) → 앱이 뜨고 가게가 기본값으로 채워져야 함 — Task 1 `cleanStall` 시험.
2. **칸 결과에 같은 물건이 여러 번·수백 행**(`SELECT name FROM items, order_items` 같은 것, 8장 `GROUP BY` 없이 `order_items`) → 한 칸 안에서는 물건마다 한 번만 행동, 하루는 정상 진행 — Task 3 `acceptRows` 시험.
3. **돈이 바닥난 채 채우기** → 앞 행부터 살 수 있는 만큼만, 돈은 0 아래로 안 감, 「돈이 모자라 못 채움」 사건 — Task 4 시험.
4. **전체 조립에서 name·item_id 없는 결과·오류·시간 초과** → 그 칸만 쉬고 이유가 장부에, 다른 칸과 하루는 진행 — Task 3·4 시험.
5. **「장 열기」를 빨리 두 번 누르거나 재생 중 화면을 떠남** → 하루는 한 번만 지나고, 상태는 재생 전에 저장됨 — Task 7 화면 시험.
