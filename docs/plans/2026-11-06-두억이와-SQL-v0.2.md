> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 1~6장에 심화 레슨 18개(`1-A1`~`6-A3`)를 넣고, 점검기가 심화를 본 과정과 같은 규칙으로 검사하게 한다.

**Architecture:** 심화 엔진(열림·가지·보상·배지)과 빌드(`ADVANCED` 묶기)는 v0.1에 이미 있다. 이번 판은 점검기(`tests/content.js`)에 `ADVANCED` 검사와 심화 전용 낱말(`data/grammar.js`의 새 `ADVANCED_GRAMMAR`)을 더하고, 디딤돌 조사로 본 과정 빈틈을 메운 뒤, 장마다 심화 3레슨을 쓴다.

**Tech Stack:** ESM JS(Node `node --test`), sql.js 1.15.2, Python 3 + Playwright Chromium(`PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers`), esbuild(`build.py`).

**Spec:** `docs/specs/2026-11-06-심화-1-6장-설계.md` (본 설계: `docs/specs/2026-11-05-두억이와-SQL-설계.md`, 쓰기 안내: `docs/lesson-writing-guide.md`)

## Global Constraints

- 심화의 성격: A1·A2는 그 장 주제를 더 깊게(뒷장 문법을 미리 쓰지 않음), A3는 장터 「의뢰」 응용 (설계 A1·A4)
- 읽기 SQL만: INSERT·UPDATE·DELETE·CREATE 없음 (설계 A3, 본 설계 D11)
- 타자 없음: 터치·카드 조립만 (본 설계 D8)
- 레슨 id `N-A1`~`N-A3`, 장 파일 `ADVANCED` 목록, `isAdvanced: true`, 장마다 정확히 3개, `isExam` 없음
- 레슨 크기·문제 수·조립 수·카드 상한은 본 과정 같은 장과 같음(쓰기 안내 §2), 카드 더미 12장 이하(R34·R47)
- 엔진마다 다른 동작은 「이 장터에서는」(R36), 별칭은 영어(R32), 화폐는 「N엽전」(R31), 빈칸=NULL·빈자리=칸(R35)
- 심화 전용 낱말·심화 개념은 본 과정 레슨·매일 도전 틀에 쓰지 못함
- 데이터 사실은 `data/market.sql`로 확인한 것만, 민속 사실 주장 없음, 다른 저장소 문제·글 베끼지 않음
