# 실기기 확인 목록 — 두억이와 SQL! v0.1 (아이폰 17 · 사파리)

개발 환경에는 사파리 엔진(WebKit)과 실제 아이폰이 없어서, 아래 항목은 **직접 아이폰에서 확인**해 주셔야 해요. 화면 시험은 Chromium(크롬의 바탕 브라우저)에 아이폰 17 화면 크기만 입혀서 했어요.

특히 **사파리에서 SQL 실행기(`sql-wasm.wasm`, WebAssembly 파일)를 오프라인으로 쓰는 것**(13·14번)과 **홈 화면 앱**(12번)은 Chromium 시험으로는 확인할 수 없는 부분이에요.

## 준비

1. `python3 build.py`로 만든 `dist/` 폴더를 HTTPS(자물쇠가 있는 주소) 웹 공간에 올려요(예: GitHub Pages). 홈 화면 앱과 오프라인 저장은 HTTPS에서만 동작해요.
2. 아이폰 17의 **사파리**로 그 주소를 열어요. (다른 앱 안의 브라우저 말고 사파리)
3. 처음 확인할 때는 「설정 → 앱 → Safari → 방문 기록 및 웹 사이트 데이터 지우기」로 깨끗한 상태에서 시작하면 좋아요. (같은 주소의 「리아와 파이썬!」 진도도 함께 지워지니, 리아 쪽은 먼저 「저장 내보내기」를 해 두세요)
4. 시간을 잴 때는 아이폰 시계 앱의 스톱워치를 쓰면 충분해요.

## 알려 주는 방법

- 항목 번호와 **정상 / 이상**만 적어 주셔도 돼요. 예: 「1 정상(1.2초), 2 와이파이 3초·LTE 7초, 13 이상 — 비행기 모드에서 「실행기 준비 중이에요」에서 멈춤(캡처 첨부)」
- 캡처는 측면 버튼 + 볼륨 올리기 버튼을 함께 눌러 찍어요.
- 아이폰의 iOS 버전(「설정 → 일반 → 정보 → iOS 버전」)도 함께 알려 주세요.
- 받은 결과는 `LOG.md`의 다음 판 「검증」 칸에 날짜와 함께 기록해요.
